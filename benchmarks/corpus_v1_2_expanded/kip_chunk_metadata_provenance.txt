Every chunk generated by ChunkingService carries structured metadata for downstream provenance attribution.
The Chunk domain model encapsulates id, document_id, text, index, character_count, and metadata dict.
Provenance fields populated during ingestion include source_filename, chunk_index, and media_type.
When chunks are embedded, EmbeddingService preserves this provenance by copying it into EmbeddingInput.metadata.
The vector store provider stores these metadata attributes inside the Qdrant payload alongside the vector.
When a search query retrieves candidate vectors, the vector store returns the payload text and provenance.
RAG response models package retrieved chunks into source references displayed to users in the Streamlit UI.
This immutable provenance chain guarantees that generated answers can be audited down to exact chunk indices.
